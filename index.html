Introduction

This interactive documentation explains the WebSim multiplayer capabilities, providing details about WebSocket connections, peer management, messaging, and persistent data storage. This guide will help you understand how to build real-time collaborative experiences.

WebSocket Connection

The WebsimSocket is the foundation for multiplayer functionality:

// Connect to the WebSocket server
const room = new WebsimSocket();

The connection is automatically established when you create a new WebsimSocket instance.

Peers & Clients

Client Information

// Access current client's information
let clientId = room.party.client.id;
let username = room.party.client.username;
console.log(clientId, username);

Client information is automatically handled by the library. You can use:

  • client.id for client-specific logic
  • client.username for display purposes

Connected Peers

// Access all connected peers (including yourself)
for (const clientId in room.party.peers) {
    const { username } = room.party.peers[clientId];
    console.log(username);
}

// Subscribe to peer changes
room.party.subscribe((peers) => {
    for (const clientId in peers) {
        const { username } = peers[clientId];
        console.log(username);
    }
});

React Integration

// React 18 integration with useSyncExternalStore
const peers = React.useSyncExternalStore(
    room.party.subscribe,
    () => room.party.peers,
);

Events

Sending Events

Events are ephemeral messages sent between connected clients:

// Send a custom event
room.send({
    type: "yourCustomEventType",
    echo: true,  // Whether the sender receives the event (default: true)
    // Additional event data
    newX: 100,
    newY: 100,
    message: "Hello, world!",
});

Handling Events

// Handle incoming events
room.onmessage = (event) => {
    const data = event.data;
    switch (data.type) {
        // Built-in events
        case "connected":
            console.log(`Client ${data.clientId}, ${data.username}`);
            break;
        case "disconnected":
            console.log(`Client ${data.clientId}, ${data.username}`);
            break;
            
        // Custom events
        case "yourCustomEventType":
            console.log(`New position: (${data.newX}, ${data.newY})`);
            console.log(`Message: ${data.message}`);
            console.log(`Event sent by client: ${data.clientId}`);
            console.log(`Event sent by username: ${data.username}`);
            // Handle your custom event
            break;
            
        default:
            console.log("Received event:", data);
    }
};

Persistent Records

Unlike events, records are persistent and remain available even after clients disconnect.

Creating Records

// Create a new record
let post = await room.collection('post').create({
    message: "Hello, world!",
});

Records automatically include:

  • id - Unique identifier
  • username - Creator's username
  • created_at - UTC timestamp

Retrieving Records

// Get all records of type "post"
let posts = room.collection('post').getList();

// Filter records by field value
let filteredPosts = room.collection('post').filter({ parent_id: post.id }).getList();

// Get only top-level posts
let topPosts = room.collection('post').filter({ parent_id: null }).getList();

Note: getList() always returns records sorted from newest to oldest.

Record Relationships

// Create related records
let post = await room.collection('post').create({
    message: "Hello, world!",
});

// Create an upvote related to the post
let upvote = await room.collection('upvote').create({
    post_id: post.id,
});

// Query all upvotes on a specific post
let upvotes = room.collection('upvote').filter({ post_id: post.id }).getList();

Updating & Deleting Records

// Update a record (can only update your own records)
await room.collection('post').update(post.id, {
    message: "Hello, world! (updated)",
});

// Delete a record (can only delete your own records)
await room.collection('post').delete(post.id);

Subscribing to Record Changes

// Subscribe to all posts
room.collection('post').subscribe(function (posts) {
    console.log(posts);
});

// Subscribe to filtered posts
room.collection('post').filter({ parent_id: null }).subscribe(function (topLevelPosts) {
    console.log(topLevelPosts);
});

// Unsubscribe when needed
const unsubscribe = room.collection('post').subscribe(function (posts) {
    console.log(posts);
});
unsubscribe();

React Integration

// React 18 integration
const messages = React.useSyncExternalStore(
    room.collection('message').subscribe,
    room.collection('message').getList

// With filtering
const topMessages = React.useSyncExternalStore(
    room.collection('message').filter({ parent_id: null }).subscribe,

File Upload

WebSim provides a simple way to upload files:

try {
    // Upload file to S3 and get the URL
    const url = await websim.upload(file);
    console.log("File uploaded:", url);
} catch (error) {
    console.error('Error uploading file:', error);
}

LLM Integration

Basic AI Chat

let conversationHistory = [];

// Add user message
const newMessage = {
    role: "user",
    content: "What is two plus two?",
};
conversationHistory.push(newMessage);

// Only keep recent messages
conversationHistory = conversationHistory.slice(-10);

// Get AI response
const completion = await websim.chat.completions.create({
    messages: [
        {
            role: "system",
            content: "You are a friendly assistant who speaks in rhyming verse.",
        }, // system message is optional
        ...conversationHistory,
    ],
});

const response = completion.content;
// Add response to history
conversationHistory.push(completion);

JSON Output

const completion = await websim.chat.completions.create({
    messages: [
        {
            role: "system",
            content: `Combine the following concepts into a single, coherent idea.
Respond directly with JSON, following this JSON schema, and no other text.
{
  concept: string;
  emoji: string;
}
`,
        },
        {
            role: "user",
            content: [
                { type: "text", text: "eggs + fire" },
            ],
        },
    ],
    json: true,
});

const result = JSON.parse(completion.content);
let concept = result.concept;
let emoji = result.emoji;

AI Image Generation

// Generate an image with default 1:1 aspect ratio
const result = await websim.imageGen({
    prompt: "A crayon child's drawing of a turtle",
});

// Generate with specific aspect ratio
const wideResult = await websim.imageGen({
    prompt: "A beautiful sunset over a calm ocean",
    aspect_ratio: "16:9",
});

// Generate with specific dimensions
const customResult = await websim.imageGen({
    prompt: "A beautiful sunset over a calm ocean",
    width: 1024,
    height: 768,
});

// Use a seed for consistent variations
const seededResult = await websim.imageGen({
    prompt: "A beautiful sunset over a calm ocean",
    seed: 4,
});

console.log(result.url); // URL to the generated image

API Access

// Access user info
const { id, username, avatar_url } = user;

// Get user following
const response = await fetch(`/api/v1/users/${username}/following`);
const body = await response.json();
for (const {follow} of body.following.data) {
    // Process following data
}
